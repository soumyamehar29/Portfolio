Hybrid U-Net and Vision Transformer Architecture for Brain Tumor Segmentation from MRI Scans with Explainability

A research-oriented deep learning project exploring the combination of U-Net and Vision Transformer architectures for brain tumor segmentation from MRI scans, with explainability as an additional objective.

Implementation Highlights

  • Trained and evaluated on the benchmark BraTS2020 MRI dataset
  • Implemented using PyTorch for modular deep learning experimentation
  • Hybrid architecture coupling U-Net's spatial feature localization with Vision Transformer's long-range self-attention
  • Targeting multi-class tumor sub-region segmentation
  • Incorporating Grad-CAM++ visual explainability to generate interpretable attention heatmaps
  • Planned web interface for MRI slice upload and segmentation visual inspection
Academic Research Disclaimer: This project is exploratory and actively in progress. It is not clinically validated and does not constitute a diagnostic medical tool. Model evaluation and iterative performance refinements are ongoing.
